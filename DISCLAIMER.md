## 2. Strict Asset & ROM Policy (NFR-01 Compliance)
To strictly respect intellectual property rights and maintain open-source distribution integrity:
1. **Zero Bundled Assets**: This repository and all binary releases **do not contain any copyrighted game ROMs, proprietary artwork, character sprites, or proprietary audio assets**.
2. **Dynamic Community Cache**: All sprites, animated GIF frames, and audio cries are requested at runtime from public educational/community REST endpoints (such as [PokéAPI](https://pokeapi.co) and the Showdown community project) directly by the end user's machine and cached locally in `%APPDATA%\WinTokenMon\`.

## 3. Privacy & Offline Data Integrity
- **100% Local Data Processing**: WinTokenMon runs completely on your local machine. It reads local token usage logs generated by CLI tools (such as Antigravity CLI, Claude Code, Cursor IDE, Codex CLI, and GitHub Copilot CLI).
- **Zero Telemetry / Zero Uploads**: WinTokenMon **never** transmits, stores, or uploads your codebase, prompt text, AI conversations, or API credentials to any third-party server.
