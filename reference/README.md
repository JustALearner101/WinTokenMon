## 🪟 How the Windows Port Differs

While the original macOS edition lives primarily in the macOS Menu Bar via SwiftUI / AppKit, **PokeTokenBar for Windows** introduces native Windows paradigms:
- **Frameless Floating Desktop Pet (Shimeji-style)** with transparent colorkey overlay and autonomous roaming / walking animations.
- **Windows System Tray Integration** with live token tooltips and quick actions.
- **Windows Native Toast Notifications** for daily token limit warnings (80% and 100% budget alerts).
- **Embedded Audio Engine**: Authentic Pokémon cries via PokéAPI and retro 8-bit level-up arpeggios synthesized in-memory.
- **Multi-Provider File Scanner**: Automated local log discovery across Antigravity CLI (Protobuf DBs), Claude Code (JSONL), Cursor IDE (SQLite), Codex CLI (JSONL), and GitHub Copilot CLI (SQLite).
