**WinTokenMon** adalah aplikasi utilitas developer buatan penggemar, open-source, dan non-komersial yang dibuat semata-mata untuk produktivitas pribadi dan tujuan edukasi.

- Proyek ini adalah karya penggemar independen dan **TIDAK** berafiliasi dengan, didukung oleh, disponsori oleh, atau disetujui secara resmi oleh Nintendo, Game Freak, Creatures Inc., atau The Pokémon Company.

---

## 2. Kebijakan Ketat Aset & ROM (Kepatuhan NFR-01)
Untuk sepenuhnya menghormati hak kekayaan intelektual dan menjaga integritas distribusi open-source:
1. **Bebas Bundel Aset**: Repositori ini dan semua rilis biner **tidak mengandung ROM game berhak cipta, artwork proprietary, sprite karakter komersial, atau file audio komersial**.
2. **Cache Komunitas Dinamis**: Semua sprite, frame GIF animasi, dan suara cry diunduh pada saat aplikasi berjalan dari REST endpoint publik/komunitas edukasi (seperti [PokéAPI](https://pokeapi.co) dan proyek komunitas Showdown) langsung oleh komputer pengguna dan disimpan secara lokal di `%APPDATA%\WinTokenMon\`.
3. **Bukan untuk Komersial**: Perangkat lunak ini 100% gratis, open-source di bawah Lisensi MIT, dan tidak memiliki iklan, monetisasi berbayar, langganan, atau transaksi komersial apapun.

---

## 3. Privasi & Integritas Data Lokal
- **Pemrosesan Data 100% Lokal**: WinTokenMon berjalan sepenuhnya di komputer lokal Anda. Aplikasi hanya membaca file log penggunaan token yang dihasilkan oleh CLI tools lokal Anda.
- **Tanpa Telemetri / Tanpa Upload**: WinTokenMon **tidak pernah** mengirimkan, menyimpan di cloud, atau mengunggah kode sumber, teks prompt, riwayat percakapan AI, ataupun kredensial API Anda ke server pihak ketiga mana pun.
